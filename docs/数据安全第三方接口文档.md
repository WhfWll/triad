# 数据安全第三方接口文档

本文档面向第三方系统调用，聚焦“一体化安全检查平台”中的 **数据安全** 模块。

当前数据安全包含两类任务：

1. **数据库安全检查**
2. **敏感数据扫描**

推荐第三方系统按以下流程完成对接：

1. 创建任务
2. 轮询任务详情获取状态和结果
3. 生成安全检查报告
4. 获取报告详情并保存为 HTML

---

## 1. 鉴权说明

当前第三方调用推荐使用 **平台 API 秘钥** 鉴权。

- 请求头名称：`platform-token`
- 值来源：系统配置 -> `API秘钥` 页签中生成的秘钥

示例：

```http
platform-token: 你的API秘钥
Content-Type: application/json
```

## 2. 接口总览

| 场景 | 方法 | 路径 |
| --- | --- | --- |
| 数据库连接测试 | `POST` | `/smart/datasec/db/test-conn` |
| 创建数据库安全检查任务 | `POST` | `/smart/datasec/db/run` |
| 数据库安全检查任务列表 | `GET` | `/smart/datasec/db/list` |
| 数据库安全检查任务详情 | `GET` | `/smart/datasec/db/detail` |
| 创建敏感数据扫描任务 | `POST` | `/smart/datasec/sensitive/run` |
| 敏感数据扫描任务列表 | `GET` | `/smart/datasec/sensitive/list` |
| 敏感数据扫描任务详情 | `GET` | `/smart/datasec/sensitive/detail` |
| 生成安全检查报告 | `POST` | `/smart/security/report/generate` |
| 获取报告详情（用于下载） | `GET` | `/smart/security/report/detail` |

说明：

- 数据安全当前同样没有单独的 `progress` 接口
- 第三方可通过 `detail` 接口轮询任务状态和结果

## 3. 数据库连接测试

### 3.1 请求信息

- 方法：`POST`
- 路径：`/smart/datasec/db/test-conn`
- Content-Type：`application/json`

### 3.2 请求体示例

```json
{
  "dbType": 1,
  "dbHost": "192.168.22.142",
  "dbPort": 3306,
  "dbName": "testdb",
  "dbUser": "root",
  "dbPassword": "123456"
}
```

### 3.3 成功响应示例

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "ok": true,
    "message": "连接成功：MySQL 192.168.22.142:3306/testdb"
  }
}
```

## 4. 创建数据库安全检查任务

### 4.1 请求信息

- 方法：`POST`
- 路径：`/smart/datasec/db/run`

### 4.2 请求体示例

```json
{
  "name": "MySQL 安全检查",
  "dbType": 1,
  "targets": [
    {
      "dbHost": "192.168.22.142",
      "dbPort": 3306,
      "dbName": "triad",
      "dbUser": "root",
      "dbPassword": "123456"
    }
  ],
  "scanSensitive": true,
  "dataTypes": [1, 2, 3],
  "scanAllDb": false
}
```

### 4.3 主要字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 否 | 任务名称 |
| `dbType` | int | 是 | 数据库类型 |
| `targets` | array | 否 | 直接传目标库列表 |
| `libraryTargetIds` | array | 否 | 从目标库引用已有目标 ID 列表 |
| `scanSensitive` | bool | 否 | 是否同时附带敏感数据扫描 |
| `dataTypes` | array | 否 | 敏感数据类型列表 |
| `scanAllDb` | bool | 否 | 是否扫描实例中的全部库 |

### 4.4 常见 `dbType` 参考

| 值 | 说明 |
| --- | --- |
| `1` | MySQL |
| `2` | PostgreSQL |
| `3` | MongoDB |
| `4` | Redis |
| `5` | CouchDB |

### 4.5 成功响应示例

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": "530900100"
  }
}
```

## 9. 获取报告并下载 HTML

### 9.1 报告详情接口

- 方法：`GET`
- 路径：`/smart/security/report/detail`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | int | 是 | 报告 ID |

响应示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 206,
    "title": "数据安全检查报告 #530900100",
    "module": "data",
    "taskId": 530900100,
    "content": "<!DOCTYPE html><html><head>...</head><body>...</body></html>"
  }
}
```

说明：

- 当前没有单独的下载流接口
- 第三方应读取 `content`，再按 `text/html` 保存为 `.html` 文件

## 10. 对接流程示例

### 数据库安全检查

1. `POST /smart/datasec/db/run`
2. `GET /smart/datasec/db/detail?id=任务ID`
3. `POST /smart/security/report/generate`
4. `GET /smart/security/report/detail?id=报告ID`

### 敏感数据扫描

1. `POST /smart/datasec/sensitive/run`
2. `GET /smart/datasec/sensitive/detail?id=任务ID`
3. `POST /smart/security/report/generate`
4. `GET /smart/security/report/detail?id=报告ID`
