## 1. 系统登录

## 3. 主机安全

主机安全模块支持**安全配置核查**、**CVE 漏洞扫描**和**恶意代码检测**三大功能。

### 3.1 任务管理

路径：左侧导航 → **主机安全** → **任务管理**

#### 3.1.1 安全配置核查任务

**功能**：对目标主机执行基线安全配置检查，验证是否符合安全配置标准。

**新建任务**：

1. 点击「新建任务」按钮
2. 选择「安全配置核查」
3. 填写目标主机信息（IP、端口、用户名、密码/密钥、操作系统类型）
4. 点击「确定」提交任务

> **[截图区域：新建配置核查任务表单]**

**查看结果**：

- 任务列表展示所有任务的检查状态、通过率、时间等信息
- 点击任务可查看详情，包括概况统计、检测项列表、执行日志

> **[截图区域：配置核查任务列表]**
> **[截图区域：任务详情-概况页]**
> **[截图区域：任务详情-检测项列表]**
> **[截图区域：任务详情-执行日志]**

#### 3.1.2 CVE 漏洞扫描任务

**功能**：扫描主机系统软件包，匹配已知 CVE 漏洞库，发现安全漏洞。

**新建任务**：点击「新建任务」→ 选择「CVE 漏洞扫描」→ 填写主机信息 → 提交。

> **[截图区域：新建 CVE 扫描任务]**

**查看结果**：任务完成后可查看漏洞详情（CVE 编号、影响软件包、风险等级、修复建议）。

> **[截图区域：CVE 漏洞扫描详情]**

#### 3.1.3 恶意代码检测任务

**功能**：基于 YARA 规则对目标主机进行恶意代码/后门文件扫描。

**新建任务**：点击「新建任务」→ 选择「恶意代码检测」→ 填写主机信息 → 提交。

> **[截图区域：新建恶意代码检测任务]**

### 3.2 规则管理

#### 3.2.1 配置核查规则

路径：**主机安全** → **配置核查规则**

支持查看、导入、新增、编辑、删除核查规则。每条规则包含：

- 规则名称 / 描述
- 适用操作系统（Linux / Windows / 国产系统 / 嵌入式）
- 检查命令
- 期望值及匹配方式
- 风险等级及修复建议

> **[截图区域：配置核查规则列表]**
> **[截图区域：规则详情/编辑]**

#### 3.2.2 漏洞扫描规则

路径：**主机安全** → **漏洞扫描规则**

管理 CVE 漏洞匹配规则库，支持导入和更新。

#### 3.2.3 病毒库规则

路径：**主机安全** → **病毒库规则**

管理 YARA 病毒检测规则，支持导入自定义规则。

## 4. 应用安全

### 4.1 任务管理

路径：左侧导航 → **应用安全** → **任务管理**

#### 4.1.1 动态扫描任务

**功能**：对 Web 站点进行主动式漏洞扫描。

**新建任务**：

1. 点击「新建任务」
2. 选择「动态扫描」
3. 填写目标 URL、扫描策略等配置
4. 提交 → 系统自动执行扫描

> **[截图区域：新建动态扫描任务]**

#### 4.1.2 专项应用检测任务

**功能**：针对特定应用框架或中间件的安全检测。

### 4.2 扫描策略

路径：**应用安全** → **扫描策略**

管理扫描策略模板，可自定义：

- 扫描深度
- 检测插件范围
- 请求速率
- 登录会话配置

> **[截图区域：扫描策略列表]**
> **[截图区域：扫描策略编辑]**

### 4.3 漏洞库

路径：**应用安全** → **漏洞库**

查看应用安全检测插件库，支持按类型、风险等级筛选。

## 5. 数据安全

### 5.1 任务管理

路径：左侧导航 → **数据安全** → **任务管理**

#### 5.1.1 数据库安全检查任务

**功能**：对 MySQL、PostgreSQL、MongoDB、Redis 等数据库执行安全配置检查。

**新建任务**：

1. 点击「新建任务」
2. 选择「数据库安全检查」
3. 填写数据库连接信息（类型、主机、端口、账号密码）
4. 提交

> **[截图区域：新建数据库检查任务]**

#### 5.1.2 敏感数据发现任务

**功能**：扫描数据库中的敏感数据（身份证、手机号、银行卡等个人信息）。

**新建任务**：填写数据库连接信息 → 选择扫描范围 → 提交。

> **[截图区域：新建敏感数据扫描任务]**

### 5.2 数据库目标库

路径：**数据安全** → **数据库目标库**

集中管理数据库连接信息，支持批量导入/导出，新建任务时可直接从目标库选择。

> **[截图区域：数据库目标库列表]**

### 5.3 检测规则

路径：**数据安全** → **检测规则**

- **数据库检查规则**：数据库安全配置的检查项
- **敏感数据规则**：定义敏感数据匹配模式（正则表达式）

> **[截图区域：检测规则列表]**

## 附录

### A. 常见问题

**Q: 新建任务后刷新页面任务消失？**  
A: 请检查任务是否正在执行中。任务创建后系统后台异步执行，短暂延迟后即可在列表中看到。

**Q: 执行日志为什么在任务运行中显示内容较少？**  
A: 每条规则检查完成后会立即写入日志，页面每 2 秒自动刷新，请稍候片刻即可看到实时结果。

**Q: 连接目标主机失败？**  
A: 请检查：
- 目标主机 IP / 端口是否正确
- 用户名密码或密钥凭据是否正确
- 目标主机防火墙是否放行对应端口
- 网络连通性
