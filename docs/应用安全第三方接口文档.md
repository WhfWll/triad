# 应用安全第三方接口文档

本文档面向第三方系统调用，聚焦“一体化安全检查平台”中的 **应用安全动态扫描** 能力。

推荐第三方系统按以下流程完成对接：

1. 创建动态扫描任务
2. 轮询任务详情获取状态和结果
3. 生成安全检查报告
4. 获取报告详情并保存为 HTML

---

## 1. 鉴权说明

当前第三方调用推荐使用 **平台 API 秘钥** 鉴权。

- 请求头名称：`platform-token`
- 值来源：系统配置 -> `API秘钥` 页签中生成的秘钥

示例：

```http
platform-token: 你的API秘钥
Content-Type: application/json
```

---

## 2. 接口总览

| 场景 | 方法 | 路径 |
| --- | --- | --- |
| 创建动态扫描任务 | `POST` | `/smart/appsec/dynamic/run` |
| 动态扫描任务列表 | `GET` | `/smart/appsec/dynamic/list` |
| 动态扫描任务详情 | `GET` | `/smart/appsec/dynamic/detail` |
| 生成安全检查报告 | `POST` | `/smart/security/report/generate` |
| 获取报告列表 | `GET` | `/smart/security/report/list` |
| 获取报告详情（用于下载） | `GET` | `/smart/security/report/detail` |

说明：

- 应用安全当前没有单独的 `progress` 接口
- 第三方系统可通过 `detail` 接口轮询任务状态和扫描结果

## 3. 创建动态扫描任务

### 3.1 请求信息

- 方法：`POST`
- 路径：`/smart/appsec/dynamic/run`
- Content-Type：`application/json`

### 3.2 请求体示例

```json
{
  "name": "门户动态扫描",
  "target": "http://demo.test.local",
  "targetUrl": "http://demo.test.local",
  "appType": 1,
  "strategy": "",
  "testMode": "web",
  "safeTest": true,
  "vulExploit": false,
  "testIntensity": 2,
  "vulIdsConfig": [],
  "websiteLogin": {},
  "webCrawler": {},
  "portScan": {},
  "proxy": {},
  "webPathScan": {},
  "weakPass": {}
}
```

### 3.3 常用字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 否 | 任务名称 |
| `target` | string | 建议填 | 扫描目标，可传单个或多个 URL/域名文本 |
| `targetUrl` | string | 可选 | 单目标 URL，和 `target` 二选一即可 |
| `appType` | int | 否 | 应用类型 |
| `strategy` | string | 否 | 扫描策略 ID |
| `testMode` | string | 否 | 测试模式 |
| `safeTest` | bool | 否 | 是否安全测试 |
| `vulExploit` | bool | 否 | 是否启用漏洞利用验证 |
| `testIntensity` | int | 否 | 测试强度 |
| `vulIdsConfig` | array | 否 | 指定漏洞脚本 ID 列表 |

### 3.4 成功响应示例

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": "420800100"
  }
}
```

说明：

- 返回的 `id` 为应用安全任务 ID

- 轮询间隔：`3 ~ 5 秒`
- 当 `status = 3` 时，可视为任务完成

## 5. 生成应用安全报告

### 5.1 请求信息

- 方法：`POST`
- 路径：`/smart/security/report/generate`

### 5.2 请求体示例

```json
{
  "module": "app",
  "taskId": 420800100
}
```

### 5.3 成功响应示例

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 205
  }
}
```

说明：

- 返回的 `id` 为安全检查报告 ID

---

## 6. 获取报告并下载 HTML

### 6.1 报告列表

- 方法：`GET`
- 路径：`/smart/security/report/list`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | int | 是 | 页码 |
| `size` | int | 是 | 每页条数 |

### 6.2 报告详情

- 方法：`GET`
- 路径：`/smart/security/report/detail`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | int | 是 | 报告 ID |

响应示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 205,
    "title": "应用安全检查报告 #420800100",
    "module": "app",
    "taskId": 420800100,
    "content": "<!DOCTYPE html><html><head>...</head><body>...</body></html>"
  }
}
```

说明：

- 当前没有单独的“下载流”接口
- 第三方应读取 `content`，再按 `text/html` 保存为 `.html` 文件

---

## 7. 对接流程示例

1. `POST /smart/appsec/dynamic/run`
2. `GET /smart/appsec/dynamic/detail?id=任务ID`
3. `POST /smart/security/report/generate`
4. `GET /smart/security/report/detail?id=报告ID`
