## 2. 主机安全检查

- 具备对服务器、终端、用户计算机、工控设备、物联网设备（含虚拟机和容器）等进行全面的安全配置核查、漏洞扫描和恶意代码检测能力。
- 并发扫描能力为 **10** 个。
- 支持不同主机操作系统种类 **4** 种，包括 Linux/Unix 系统、Windows 系统、国产操作系统、嵌入式 OS 等。
- 内置漏洞检测规则 **1200+** 条，包括但不限于内核漏洞、权限漏洞、密码策略、防火墙、网络访问等规则。
- 具备分类管理的能力，可以对主机审查功能分类管理。
- 具备审查结果导出能力，可以生成审计日志。
- 具备用户管理能力，可以对用户行为进行记录。
- 具备历史记录查看能力，可以查看历史审查功能记录。

## 3. 应用安全检查

- 具备在应用程序运行状态下，对其进行动态的安全测试，模拟真实攻击以发现运行时暴露的安全漏洞能力。
- 并发扫描能力为 **5** 个。
- 支持不同应用类型种类 **15** 种，包括但不限于万户、用友、蓝凌、云时空、亿赛通、D-Link、通达等应用。
- 内置漏洞检测规则 **7000+** 条，包括但不限于远程代码执行、未授权访问、SQL 注入、文件上传、弱口令等规则。
- 具备分类管理的能力，可以对应用审查功能分类管理。
- 具备审查结果导出能力，可以生成审计日志。
- 具备用户管理能力，可以对用户行为进行记录。
- 具备历史记录查看能力，可以查看历史审查功能记录。
